# User Journeys

## Agent Journey
1. Open assigned queue.
2. Sort by SLA risk and severity.
3. Open ticket, inspect history and entitlements.
4. Run summary or reply draft.
5. Edit draft, request approval if needed.
6. Send, snooze, resolve, or escalate.

## Manager Journey
1. Monitor dashboard and approval queue.
2. Review high-risk drafts and QA sample list.
3. Approve, reject, or coach.
4. Export summary for weekly review.

## Analyst Journey
1. Inspect routing outcomes and rule conflicts.
2. Dry-run new automations.
3. Review queue aging and AI acceptance changes.
