# QA Review Checklist

- Functional: ticket state rules, approval gates, knowledge publish flow, AI disable switches.
- Security: RBAC, tenant scoping, PII redaction, audit coverage.
- Performance: queue read, search, draft latency, worker lag.
- Accessibility: keyboard triage flow, focus order, contrast, live regions.
- Documentation: API reference, environment vars, architecture notes, sprint evidence all updated.
