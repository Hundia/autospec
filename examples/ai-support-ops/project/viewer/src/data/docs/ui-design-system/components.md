# UI Components

- QueueCard: queue name, backlog count, at-risk count, assignee chip.
- TicketRow: status, subject, account, age, SLA, channel, assignee.
- DraftComposer: source citations, warning banner, confidence pill, actions.
- ApprovalPanel: approver, reason code, decision buttons, audit summary.
- KnowledgeArticleCard: status, owner, review date, freshness indicator.
- AnalyticsTile: metric, delta, sparkline, drill-down link.
