# Git Workflow

- Branch naming: `feature/sprint-<n>-<short-name>` or `fix/<ticket-id>`.
- Commit format: `type(scope): description`.
- Preferred scopes: auth, tickets, routing, ai, knowledge, qa, analytics, docs.
- PR includes ticket ids, risks, tests run, and screenshots for UI work.
- Merge strategy: squash for feature work, rebase for emergency fixes.
