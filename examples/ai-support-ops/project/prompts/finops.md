# FinOps Routing Guide

Use GPT-5 routing consistently in VS Code Copilot:
- `gpt-5.4`: sprint planning, architecture, security, debugging, and reviews.
- `gpt-5.3`: standard feature implementation and integration work.
- `gpt-5.2`: boilerplate, docs, tests, fixtures, and repetitive low-risk tasks.

Target ticket mix in backlog:
- gpt-5.2: about 40 percent
- gpt-5.3: about 45 percent
- gpt-5.4: about 15 percent

Escalate to `gpt-5.4` when a ticket changes state rules, auth, privacy, automation safety, or approval logic.
