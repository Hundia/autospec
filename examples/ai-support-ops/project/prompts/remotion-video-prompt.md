# Remotion Video Prompt

Create a Remotion v4 + TypeScript project that explains AI Support Ops in about 90 seconds. Read all files in `specs/`, `docs/`, `prompts/`, `sprints/`, and `viewer/src/data/`.

Scenes:
1. Title card with AI Support Ops, tagline, and stack badges.
2. Support operations pain points and product promise.
3. System architecture animation.
4. Ticket and knowledge data model.
5. Agent workspace and approval-gated AI draft flow.
6. API groups and state transitions.
7. Sprint roadmap and GPT-5.x routing distribution.
8. QA, audit, analytics, and privacy controls.
9. Deployment and observability.
10. Closing slide with counts for specs, docs, prompts, and sprint artifacts.

Use project colors from `docs/ui-design-system/tokens.md`. Prefer Manrope and Source Sans 3. Export MP4 and WebM.
