# Example Requirements — TodoApp

These are **example requirements** for demonstrating AutoSpec with a minimal project.

## What's in here

- `srs.md` — A concise Software Requirements Specification for a simple todo app (React + Node.js + SQLite)

## Purpose

1. **Learn by example** — See what a simple SRS looks like before writing your own
2. **Test AutoSpec** — Run `QUICKSTART.md` against a real SRS and see what gets generated
3. **Copy and adapt** — Use `srs.md` as a starting point for your own project requirements

## The example project

**TodoApp** — a straightforward todo list web app:
- Auth (email + password, JWT sessions, password reset)
- Todo CRUD (create, edit, toggle complete, delete)
- Filter views (All / Active / Completed)
- User profile management

Stack: React 18 + Node.js + SQLite
