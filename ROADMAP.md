# AutoSpec Roadmap

This document outlines the planned development milestones for AutoSpec.

## v0.2.0 — Validation & Intelligence

- **`autospec validate`** command for project structure validation
- Enhanced multi-agent coordination prompts
- Automatic dependency detection between tickets
- Template marketplace (community-contributed specs)

## v0.3.0 — Git Integration

- Git integration for automatic branch management per sprint
- PR template generation from ticket descriptions
- Sprint retrospective automation
- Metrics dashboard with velocity tracking

## v1.0.0 — Production Ready

- Stable API and config format (no more breaking changes)
- Plugin system for custom generators
- Additional IDE integrations (JetBrains, Cursor native)
- Internationalization (i18n) for prompts and templates
- Comprehensive test coverage (>90%)
